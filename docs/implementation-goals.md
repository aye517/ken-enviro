# 구현 방향 및 목표

## 프로젝트 개요

**한국환경시험원** — 대기자가측정 대행 전문기관
정확하고 신뢰할 수 있는 환경 측정 서비스를 제공하는 기관의 기업 홍보 웹사이트.
첫 방문자가 **"대기자가측정 전문기관"** 임을 즉시 파악할 수 있도록 설계한다.

---

## 핵심 목표

### 1. 즉각적인 사업 인지
- 페이지 진입 시 **대기자가측정 대행 전문기관**임이 바로 보여야 함
- 히어로 섹션: 측정 현장 이미지 + 핵심 메시지
- 주요 측정 항목이 아이콘/카드로 한눈에 노출

### 2. 주요 측정 항목 가시화

#### 대기자가측정
| 측정 항목 | 설명 |
|----------|------|
| 먼지 | 총먼지, 미세먼지 배출량 측정 |
| SOx (황산화물) | 보일러, 연소시설 배출 측정 |
| NOx (질소산화물) | 연소시설 배출 측정 |
| THC (총탄화수소) | 도장시설, 건조시설 등 유기화합물 측정 |

#### 특정대기유해물질
| 측정 항목 | 설명 |
|----------|------|
| 벤조(a)피렌 | 다환방향족 탄화수소(PAHs), 발암물질 |
| 기타 유해물질 | 아스콘, 레미콘 시설 등 특정 유해물질 |

#### 대상 시설
- 대형 빌딩 (강남, 송파, 종로 등)
- 호텔
- 관공서 (보일러, 냉온수기)
- 대학교
- 리조트
- 차량 서비스센터
- 폐기물처리시설
- 아스콘/레미콘 시설
- 도장/건조시설
- 국립박물관 등 공공시설

### 3. 서비스 상세 안내 (`/services`)
- 대기자가측정 대행이 무엇인지 설명
- 대기배출시설 자가측정 의무 및 배출허용기준 안내
- 측정 항목별 구체적 업무 범위
- 대상 시설 유형별 측정 사례
- 보일러 및 흡수식 냉온수기 측정 기준

### 4. 문의/견적 기능 (`/contact`)
- 견적 요청 및 일반 문의 폼
- 입력 항목:
  - 회사명/시설명 (필수)
  - 담당자명 (필수)
  - 연락처 (필수)
  - 이메일 (선택)
  - 시설 유형 (선택: 드롭다운)
  - 문의 내용 (필수)
- 회사 연락처 표시:
  - T. 02-6238-0100
  - E. ken241021@naver.com
- 폼 제출: Formspree 또는 EmailJS (무료, 서버 불필요)

### 5. 블로그/측정 사례 연동 (`/blog`)
- 네이버 블로그(ken241021) 글을 사이트에서 확인 가능
- 측정 사례를 통해 **실적과 전문성** 증명
- 구현 방식:
  1. **RSS 피드 파싱** (우선 시도)
  2. **수동 JSON 데이터** (RSS 불가 시 대안)
  3. **하이브리드**: 목록은 사이트에 표시, 클릭 시 네이버 블로그로 이동

### 서비스 페이지 (`/services`)
- 대기자가측정 대행 개요

- 대상 시설 유형
- 측정 절차 안내
- 관련 법규 (대기배출시설 자가측정, 배출허용기준)

### 문의 페이지 (`/contact`)
- 좌: 문의 폼
- 우: 회사 연락처 + 간단한 안내 문구

- 각 카드: 제목 + 날짜 + 장소/시설 태그
- 클릭 시 상세 내용 또는 네이버 블로그 이동
