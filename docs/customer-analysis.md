# 고객 유형 및 패턴 분석

블로그·실적 데이터 기반 분석 — 홈페이지 "고객사 유형" 섹션에 활용

---

## 측정 항목 빈도 (가장 많이 나오는 항목)

| 측정 항목 | 빈도 | 비고 |
|----------|------|------|
| 먼지 | 거의 모든 현장 | 총먼지, 미세먼지 |
| SOx / NOx | 보일러·시설 | 황산화물, 질소산화물 |
| THC | 도장시설 | 총탄화수소 |
| 벤조[a]피렌 | 특정대기유해물질 | 아스콘, 소각 등 |

---

## 주요 고객 유형

홈페이지 "고객사 유형" 섹션에 그대로 활용 가능

| 유형 | 설명 |
|------|------|
| 호텔 / 숙박시설 | 대기자가측정 (먼지, SOx, NOx) |
| 공공기관 | 박물관, 관공서 — 보일러·냉온수기 |
| 대학교 / 학교 | 교육기관 — 보일러 배출가스 검사 |
| 폐기물 처리시설 | 폐기물 처리업장 — 먼지 측정 |
| 제조업 | 도장, 아스콘 — 건설자재 생산 |
| 자동차 관련 시설 | 차량 서비스센터, 도장·건조시설 — THC |

---

## 시설 유형별 측정 사례 매핑

| 시설 유형 | 대표 사례 | 주요 측정 항목 |
|----------|----------|----------------|
| 숙박시설 | 종로 호텔, 강남 호텔 | 먼지, SOx, NOx |
| 공공시설 | 국립박물관, 종로 관공서 | 먼지, SOx, NOx |
| 교육기관 | 서울 대학교 | 먼지, SOx, NOx |
| 폐기물 처리 | 경기도 폐기물 처리시설 | 먼지 |
| 도장시설 | 하남 차량서비스센터, 자동차 도장 | 먼지, THC |
| 건설자재 | 아스콘, 레미콘 | 먼지, 특정대기유해물질 |
| 연소/소각 | 천안시 사업장, 강원도 사업장 | 벤조[a]피렌 |
