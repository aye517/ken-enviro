# 디자인 방향성

## 컨셉

**"블랙 기반 + 블루 포인트 = 기술회사 느낌"**

- 데이터 분석 회사 / 실험실 + 공학 느낌
- 깔끔하고 차가운 분위기, 모던하고 세련된 톤
- 관공서/기관 느낌 탈피 → 전문성 + 친근한 접근성 공존
- 이미지/비주얼을 풍부하게 사용하되 과하지 않게

## 컬러 팔레트

### Primary
| 용도 | 색상 | HEX |
|------|------|-----|
| 텍스트, 헤더 | 블랙 | `#111111` |
| 배경 | 화이트 | `#FFFFFF` |

### Point (로고 블루 기반)
| 용도 | 색상 | HEX |
|------|------|-----|
| 메인 블루 | 블루 | `#2F6FED` |
| 라이트 블루 | 배경용 | `#EAF1FF` |
| CTA 호버 | 다크 블루 | `#1D5BC7` |

### Sub
| 용도 | 색상 | HEX |
|------|------|-----|
| 섹션 구분 | 그레이 | `#F5F5F5` |
| 보조 텍스트 | 다크 그레이 | `#4B5563` |
| 구분선 | 라이트 그레이 | `#E5E7EB` |

### 컬러 사용 규칙
- 숫자 강조 → 블루(`#2F6FED`), 나머지 텍스트 → 블랙(`#111111`)
- CTA 버튼 → 블루 배경 + 화이트 텍스트, hover 시 다크 블루
- 배지/태그 배경 → 라이트 블루(`#EAF1FF`) + 블루 텍스트
- 초록색 남발 절대 금지

## 이미지 활용 전략

### 히어로 섹션
- 측정 현장 / 실험실 / 도시 스카이라인 / 산업 시설 + 자연 경관
- **밝은 톤 허용**: 구름 낀 하늘, 산업 시설과 푸른 산림이 어우러진 풍경 등
- 다크 오버레이 또는 밝은 배경 모두 가능 → 화이트 텍스트 또는 블랙 텍스트
- 고해상도 풀와이드 배경

### 시설/사례 이미지
- 실제 측정 대상: 빌딩 외관, 호텔, 공장, 관공서
- 블루/그레이 톤 보정 (따뜻한 톤 지양)
- 블로그 글의 대표 이미지 또는 기본 썸네일

### 이미지 톤
- 차갑고 깔끔한 이미지 위주 (밝은 톤도 허용)
- 키워드: lab, engineering, data, industrial, air quality, 환경 측정
- 산업 시설 + 환경(산림, 하늘)이 함께 보이는 이미지 가능
- 과하게 따뜻한/포근한 자연 느낌만 지양

### 소스
- **1차**: Unsplash, Pexels (무료 상업 이용)
- **2차**: 실제 현장 사진 확보 시 교체 (신뢰도 상승)
- 모든 이미지 `next/image`로 최적화

## 레이아웃 원칙

### 핵심: 미니멀
- 박스 최소화 (너무 많으면 안 됨)
- 아이콘 과다 사용 금지
- 여백으로 구분 (선/박스 대신)
- 한 섹션에 하나의 메시지
- 설명 텍스트 짧게

### 전체
- **최대 너비**: 1280px
- **섹션 간격**: 80~120px
- **모바일 퍼스트** 반응형

### 네비게이션
- 상단 고정 (sticky), 스크롤 시 배경 화이트 + 미세 shadow
- 로고 + 회사명 좌측 (KEN 굵게, KOREA ENVIRO 작게)
- 메뉴 우측: 회사소개 | 서비스 | 자료실 | 문의하기
- 모바일: 햄버거 메뉴
- 문의하기 버튼: 블루 CTA 스타일로 항상 노출

### 카드 디자인
- 최소한의 카드만 사용
- 얇은 보더 (`1px solid #E5E7EB`) 또는 미세 shadow
- `border-radius: 12px`
- 호버: shadow 미세 강화 (과한 효과 금지)
- 태그: 라이트 블루(`#EAF1FF`) 배경 + 블루 텍스트 배지

### 섹션 구분
- 배경색 교차 (화이트 ↔ `#F5F5F5`)로 자연스러운 구분

## 메인 페이지 구조

위에서 아래 순서로 구성. 각 섹션은 한 화면에 하나의 메시지.

| 순서 | 섹션 | 내용 |
|------|------|------|
| 1 | **히어로** | 슬로건("환경을 측정하고 데이터로 증명합니다") + 보조 설명(대기·유해물질·배출가스 등) + "서비스보기 >" CTA |
| 2 | **서비스 개요** | SOx, NOx, PM, THC 라벨 + 3개 서비스 카드(대기환경 측정 / 유해물질 분석 / 배출가스 평가) |
| 3 | **성과 지표** | 500+ 측정 수량, 200+ 협력 기업, 10년+ 경험 + "자세히 보러가기 >" |
| 4 | **최신 뉴스 & 자료** | 3개 아티클 카드(썸네일, 제목, 날짜) |
| 5 | **하단 CTA** | "환경 측정이 필요하신가요?" + "문의하기 >" 버튼 |
| 6 | **푸터** | 저작권, 회사소개·서비스·개인정보처리방침·이용약관 링크 |

### 히어로 슬로건
- 메인: 핵심 문구 일부 블루 강조 (예: "측정하고")
- 서브: 대기 · 유해물질 · 배출가스 측정 등 키워드 나열

### 서비스 카드
- 이미지 + 짧은 제목 + 한 줄 설명
- 예: 대기환경 측정 / 유해물질 분석 / 배출가스 평가

## 인터랙션 & 모션

| 요소 | 효과 |
|------|------|
| 스크롤 진입 | fade-in (서틀하게) |
| CTA 호버 | `#2F6FED` → `#1D5BC7` |
| 카드 호버 | shadow 미세 강화 |
| 숫자 | 카운트업 애니메이션 (선택) |
| 네비게이션 | 스크롤 시 shadow 전환 |

- 서틀한 애니메이션 위주, 과한 모션 없음
- CSS transition 기반 (JS 라이브러리 최소화)

## 톤앤매너

### 카피라이팅 톤
- 전문적이되 **친근하고 이해하기 쉽게**
- 블로그 스타일: "~했습니다", "~측정을 진행했습니다"
- 기술 용어는 쉬운 설명 병기 (예: "SOx(황산화물)")
- "안녕하세요", "편하게 문의하세요" 같은 친근한 어투 유지

### DO
- 블랙 기반 텍스트 + 블루 포인트
- 여백 넉넉하게
- 짧은 텍스트, 핵심만
- 차가운 톤 이미지
- 실적/사례를 통한 신뢰 구축 (숫자는 블루)
- 연락처(전화번호) 눈에 띄게 배치
- 데이터/실험실/공학 느낌

### DON'T (이거 하면 망함)
- 초록색 남발 ❌
- 아이콘 과다 ❌
- 설명 텍스트 길게 ❌
- 박스 너무 많음 ❌
- 관공서/기관 느낌 ❌
- 과하게 따뜻한/포근한 자연 느낌 ❌
- 컬러풀한 디자인 ❌
- 불필요한 애니메이션 ❌
